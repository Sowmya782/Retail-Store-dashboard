# Retail-Store-Data-Dashboard (Interactive Dashboard creating using Power BI)

---

## DESCRIPTION

An interactive Power BI dashboard created using retail store data to analyze sales, profit, orders, customers, and product performance.

---

## PROJECT OBJECTIVES

- Analyze overall sales and profit performance.
- Monitor key business KPIs.
- Compare sales across different regions and categories.
- Identify top-performing products.
- Understand customer and order performance.

---

## Dataset Used

<a href ="https://github.com/Sowmya782/Retail-Store-dashboard/blob/main/Retail_Store%20powerbi%20project.pbix"></a> Retail Store Dataset

---

## Questions (KPIs)

- Compare sales by region

- Compare sales by category

- Compare profit across different regions

- Find top-performing products

- Create a chart to display sales over months

- Compare sales and profit by category

- Analyze sales based on customer segments

- Identify the contribution of each region to total sales
